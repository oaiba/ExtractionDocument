##  Player Skill-Based Routes

###  Newbie Route (Low Risk)

```
Start → Edge Zone → Safe POIs → Early Extract

Recommended Path:
1. Spawn area (2-3 basic crates)
2. Guard Shacks (ammo, keys)
3. Warehouse W3/W5 (safe loot)
4. Gate 03 extraction

Expected Loot: 5-10k value
Time: 5-8 minutes
Risk: Low (avoid center)
```

###  Intermediate Route (Balanced)

```
Start → Mid Zone → Moderate POIs → Mid Extract

Recommended Path:
1. Quick spawn loot
2. Warehouses W1-W2 (weapons)
3. Office Complex (Intel items)
4. Helipad or Convoy extraction

Expected Loot: 15-30k value
Time: 10-12 minutes
Risk: Medium (PvP possible)
```

###  Veteran Route (High Risk/Reward)

```
Start → Hot Zone → Boss → Premium Extract

Recommended Path:
1. Rush to Bridge
2. Tech Labs (quest items)
3. Reactor Tower (Boss fight)
4. Floor 3 Epic Vaults
5. Helipad extraction

Expected Loot: 50-100k+ value
Time: Full match (15 min)
Risk: Extreme (guaranteed PvP)
```
