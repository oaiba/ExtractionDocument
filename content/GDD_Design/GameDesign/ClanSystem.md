## Overview

Clans create long-term social identity, shared goals, and group competition without forcing every player into organized play.

The clan system should help players find reliable squadmates and build identity across seasons. It should not make solo play feel invalid, and it should not become a gear funnel where large groups can manufacture unfair power for members.

Clan value should come from coordination, recognition, and shared progress: banners, missions, event leaderboards, social tools, and light economic convenience with strict limits.

## Clan Lifecycle

The lifecycle gives groups a reason to return together. Creation is a commitment, recruitment builds the roster, missions create weekly goals, and seasonal competition gives the clan a public story.

| Step | Action | Result |
| :--- | :--- | :--- |
| 1 | Create clan | Name, tag, leader, and initial member cap are set |
| 2 | Recruit members | Clan gains active contributors |
| 3 | Complete clan missions | Members generate clan XP and event contribution |
| 4 | Earn milestones | Clan unlocks cosmetics, caps, and social identity rewards |
| 5 | Compete in Faction Wars | Clan contribution affects leaderboard and seasonal rewards |
| 6 | Continue mission cycle | Clan has recurring reasons to play together |

## Creation Rules

Creation rules protect the namespace and reduce spam. The cost and level requirement should be high enough to discourage throwaway clans but low enough that motivated friend groups can start early.

| Requirement | Direction |
| :--- | :--- |
| Account level | Minimum level to prevent spam |
| Creation cost | Credit sink |
| Name rules | Profanity filter and uniqueness |
| Tag rules | Short, readable, moderated |
| Initial cap | Modest member cap, expandable through levels |

## Roles And Permissions

Roles should reduce administration friction while protecting members from abuse. Any action that removes players, spends shared resources, or changes clan identity needs an audit trail.

| Role | Permissions |
| :--- | :--- |
| Leader | Full control, disband, promote, bank policy |
| Officer | Invite, kick lower ranks, start missions |
| Veteran | Invite and manage mission participation |
| Member | Contribute and receive rewards |
| Recruit | Limited access until trusted |

## Clan Progression

| Source | Contribution |
| :--- | :--- |
| Clan missions | Primary clan XP |
| Faction Wars | Event contribution and leaderboard points |
| Squad extraction | Small contribution when clanmates play together |
| Donations | Controlled contribution to clan bank |

## Clan Bank

The clan bank is a cooperation feature, not a weapon pipeline. It can support event materials, cosmetic goals, and controlled shared resources, but it must not let a few wealthy players buy combat readiness for the whole roster.

| Rule | Requirement |
| :--- | :--- |
| Deposits | Credits and event materials only |
| Withdrawals | Role-gated |
| Audit log | Required |
| Power limit | Cannot create pay-to-win gear funnel |

## Clan Examples

A casual clan of friends should benefit from easy invites, shared missions, and a visible tag without needing to compete on leaderboards. The system should support low-pressure identity.

A competitive clan should have seasonal goals, Faction War contribution, and leaderboard visibility. Their advantage should come from coordination and activity, not hidden stat bonuses.

A new recruit should have limited permissions until trusted. This protects the bank, roster, and clan identity while still letting the player contribute to missions.

## Clan Failure Cases

- If clan rewards create combat power, solo and small-group players will feel forced into clans.
- If permissions are unclear, leaders and officers can accidentally abuse shared resources.
- If missions require full groups only, casual clans will stagnate.
- If clan names and tags are not moderated, social spaces degrade quickly.
