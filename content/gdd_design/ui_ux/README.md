# UI_UX

Canonical UI/UX documentation lives in the Markdown pages in this folder.

Start with:

- `Screen_Groups_Overview.md` for taxonomy and the designer-ready screen spec template.
- `_index.md` for the rendered documentation entry page.
- Lifecycle screen group pages for detailed layout, ASCII wireframes, component requirements, states, input/focus/touch, designer notes, and acceptance checklists.

Generated `.html` pages are build output and should not be edited directly.
