## 🏴 Faction Quest Templates

### Salvage Corps Quest Types

**Type A: Resource Gathering**
```
Template: "Collect [X] of [Material Type]"
Difficulty: Easy-Medium
Time: 1-2 matches

Example: "Steel Shortage"
- Collect 10 Metal Scraps
- Bonus: Find High-Grade Steel (+500 Rep)
- Reward: 1500 Credits, Worker's Toolbox
```

**Type B: Repair Missions**
```
Template: "Repair/Activate [Object] at [Location]"
Difficulty: Medium
Time: 1 match

Example: "Power Restored"
- Reach Generator Room (Reactor F1)
- Repair Generator (30 second interaction)
- Extract successfully
- Reward: 2000 Credits, Reputation +800
```

**Type C: Convoy Protection**
```
Template: "Escort [NPC/Object] to [Extraction]"
Difficulty: Hard
Time: Full match

Example: "Supply Run"
- Meet supply cart at Loading Docks
- Escort to Gate 03 (NPC takes damage)
- Protect from 3 AI ambush waves
- Reward: 4000 Credits, Reputation +1200, Rare Item
```

### Tech Syndicate Quest Types

**Type A: Data Recovery**
```
Template: "Retrieve [Data Object] from [Secure Location]"
Difficulty: Medium
Time: 1 match

Example: "Project Prometheus Files"
- Locate Server Room in Lab Beta
- Hack terminal (15 seconds, creates noise)
- Download complete, extract with drive
- Reward: 2000 Credits, Intel item, Rep +750
```

**Type B: Hack Missions**
```
Template: "Hack [System] without being detected"
Difficulty: Hard (stealth optional)
Time: 1 match

Example: "Blind Eyes"
- Disable 3 Security Cameras in Offices
- Remain undetected (bonus objective)
- Reward: 2500 Credits, Stealth bonus +500
```

### Underground Network Quest Types

**Type A: Delivery/Smuggling**
```
Template: "Transport [Package] to [Dead Drop]"
Difficulty: Medium
Time: 1 match

Example: "Hot Goods"
- Pick up package at Warehouse W2 (marked)
- Deliver to Dead Drop in Sewers
- Avoid Peacekeepers patrol (optional)
- Reward: 3000 Credits, Black Market access
```

**Type B: Elimination**
```
Template: "Eliminate [Target] in [Zone]"
Difficulty: Hard
Time: 1 match

Example: "No Witnesses"
- Kill named AI target "The Informant"
- Location: Office Complex, Floor 4
- Target has bodyguards (3 AI)
- Bonus: Retrieve documents from body
- Reward: 5000 Credits, Rep +1500
```

### Peacekeepers Quest Types

**Type A: Zone Clearing**
```
Template: "Eliminate [X] hostiles in [Zone]"
Difficulty: Medium
Time: 1 match

Example: "Clean Sweep"
- Kill 15 Scav AI in Warehouse District
- Bonus: No civilian casualties
- Reward: 2000 Credits, Ammo crate
```

**Type B: Rescue Operations**
```
Template: "Rescue [Survivor] from [Danger]"
Difficulty: Hard (timed)
Time: 1 match, time limit

Example: "Trapped"
- Locate survivor in collapsed building
- Clear 5 enemies guarding area
- Escort survivor to Convoy extraction
- Time limit: 8 minutes
- Reward: 4000 Credits, Medical supplies, Rep +1200
```

## 📅 Daily Quest System

### Daily Quest Pool (Rotating)

**Easy Tier (Pick 1):**
| Quest | Objective | Reward |
|:------|:----------|:-------|
| Loot Run | Extract with 5+ items | 500 Credits |
| Scavenger | Loot 10 containers | 400 Credits |
| Survivor | Extract 2 matches | 600 Credits |

**Medium Tier (Pick 1):**
| Quest | Objective | Reward |
|:------|:----------|:-------|
| Combat Expert | Kill 10 AI enemies | 800 Credits |
| Valuable Find | Extract with Rare+ item | 1000 Credits |

**Hard Tier (Pick 1):**
| Quest | Objective | Reward |
|:------|:----------|:-------|
| Untouchable | Extract without taking damage | 1500 Credits |
| Boss Hunter | Kill any AI Boss | 2000 Credits |

- Resets at: 00:00 UTC
- Cannot stack uncompleted quests
- Completed quests give bonus streak

## 📊 Quest Balance Guidelines

### Reward Scaling

| Difficulty | Time Est. | Credit Reward | Rep Reward |
|:-----------|:----------|:--------------|:-----------|
| Easy | 5-10 min | 500-1000 | 200-400 |
| Medium | 10-20 min | 1000-2500 | 500-800 |
| Hard | 20-30 min | 2500-5000 | 800-1200 |
| Extreme | 30+ min | 5000-10000 | 1200-2000 |

### Quest Availability Rules
- Max 3 Daily quests active
- Max 1 Weekly quest chain
- Faction quests: Unlimited (gated by reputation)
- Main Story: Sequential unlock
