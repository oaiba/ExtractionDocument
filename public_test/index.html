      MASTER DOCUMENTATION PORTAL

      This is the central repository and gateway for all documentation related to the Extraction Shooter project. It serves as the single source of truth for both the creative vision and the technical implementation of our top-down, high-stakes tactical experience.

      Project Snapshot

      Engine
      Unreal Engine 5 (C++)
      Platform
      Mobile (iOS/Android) + PC
      Genre
      Top-down Extraction Shooter

      Current Phase: Pre-Production / Core Prototyping

      Documentation Hubs

      Access the specialized documentation portals based on your role and current task.

      Design & Creative Hub
      Player experience, world-building, visual/audio aesthetics, and narrative.
      Technical & Engineering Hub
      Implementation specs, systems architecture, networking, and performance.
      AI Agent Guidelines
      Rules, workflows, and skills for AI coding agents (Gemini, Copilot, Cursor).

      Quick Start by Role

      🎨 For Design & Art Teams

      • Single Source of Truth: Always refer to the Design Hub before starting creative work
      • Visual Consistency: Follow the Style Guide for cross-platform fidelity
      • Core Loop: Keep the Core Gameplay aligned with mechanic changes
      • Asset Submission: Use Asset Guidelines for UE5 specs

      💻 For Technical & Dev Teams

      • Implementation Specs: All enums, codenames, and interfaces are in the Technical Hub
      • Performance First: Adhere to Performance Budgets
      • Task Management: Follow the Development Roadmap
      • Code Standards: Maintain modularity per Architecture docs
