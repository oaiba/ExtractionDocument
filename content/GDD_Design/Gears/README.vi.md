# Gears

Gears định nghĩa physical equipment mà operator mặc hoặc mang vào raid: armor, helmets, headsets, rigs, backpacks, secure containers, và stash-only cases. Gear power phải được earned, found, crafted, traded, hoặc quest-granted; Commerce có thể unlock cosmetics, nhưng không grant paid combat-power item instances.

## Canonical Rules

| Topic | Rule |
| ----- | ---- |
| Tier vs rarity | Tier là balance/progression bracket; rarity là scarcity/presentation/economy signal |
| No item level | Gear không có per-item level, +1/+2 upgrade power, hoặc premium stat scaling |
| Practical value | Armor class, zones, durability, repairability, weight, storage capacity, access speed, và restrictions định nghĩa real value |
| Comparison | UI phải explain trade-offs bằng text, không chỉ green/red stat deltas |
| Restricted states | Locked, contraband, insured, ineligible, protected, damaged, và broken states cần readable reasons |
