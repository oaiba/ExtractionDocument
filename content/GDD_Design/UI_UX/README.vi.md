# UI_UX

## Bắt Đầu

- `_index.md` là hub UI/UX được render.
- `Screen_Groups_Overview.md` định nghĩa screen taxonomy và designer-ready spec template.
- `Global_UX_Standards.md` định nghĩa rule chung cho interaction, focus, state, modal, accessibility, và analytics.
- Các lifecycle screen group pages chứa layout chi tiết, ASCII wireframe, component requirement, state, input/focus/touch, designer notes, và acceptance checklist.

Tài liệu UI/UX canonical nằm trong các Markdown page trong thư mục này.

Các file `.html` generated là build output và không nên sửa trực tiếp.
