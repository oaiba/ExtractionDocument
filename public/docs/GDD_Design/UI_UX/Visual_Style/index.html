    Visual Style & Art Guidelines#

    ← Back to Index | UX Flows ←

    🎨 Visual Identity#

    Style: Grounded Neo-Industrial Era: Post-Collapse (Near Future 2035)

    Design Philosophy#

    • Decay with Memory: Every rusted panel was once new. Every ruin was a home. The world is overgrown, not just dirty.
    • Tactical Clarity: Gameplay elements (cover, loot, enemies) must be instantly readable against the chaotic background.
    • Functional Fashion: Gear looks practical. No glowing magical armor. Duct tape, zip ties, and worn metal.

    🌈 Global Color Palette#

    Primary Game Colors (Interactive)#

    Used for UI and Gameplay Feedback.

    Role Color Name Hex Usage
    Friendly Tactical Blue #3B82F6 Minimap Markers, Squad HUD
    Hostile Critical Red #EF4444 Enemy Highlights, Damage Indicators
    Loot Neon Yellow #FACC15 Interactive Objects, Pickup Prompts
    Objective Signal Green #22C55E Mission Markers, Exfil Zones
    Neutral Steel Gray #6B7280 HUD Backgrounds, Non-Interactive UI

    Environmental Base (Atmospheric)#

    Used for Level Design and Lighting.

    Category Color Usage
    Industrial Rust Orange (#D97706) Metal structures, decaying machinery
    Urban Concrete Gray (#94A3B8) Buildings, roads, rubble
    Nature Overgrowth Green (#166534) Vines, moss reclaiming the city
    Lighting Sodium Vapor (#FBBF24) Streetlights, old factory lamps
    Darkness Shadow Blue (#1E293B) Deep shadows (contrast with light)

    🔠 Typography#

    Primary Font: “Oxanium” (Google Fonts)#

    Usage: Headings, UI Headers, Important Stats. Style: Cyber-Tech but legible. Square shapes.

    Secondary Font: “Inter” (Google Fonts)#

    Usage: Body text, Item descriptions, Dialogue. Style: Clean, sans-serif, highly readable at small sizes.

    Font Hierarchy#

    1. H1 (Screen Title): 48px, Bold, Uppercase.
    2. H2 (Section Header): 32px, Semi-Bold.
    3. Body (Descriptions): 16px, Regular.
    4. Micro (Stats): 12px, Mono-spaced (for numbers).

    🖼️ Iconography Style#

    • Style: Flat, Simplified Vectors. No gradients.
    • Stroke: 2px consistent stroke width.
    • Fill: Transparent or solid depending on state.
    • Metaphor: Real-world objects (e.g., a “Medkit” icon looks like a military IFAK, not a generic cross).

    Icon Set Examples#

    • Weapon: Silhouette of an AK-47 (Specific, not generic “gun”).
    • Armor: Plate Carrier vest.
    • Ammo: Specific caliber bullet shape (5.56 vs 9mm).
    • Health: Cross inside a tactical pouch.

    💡 Lighting Design (Readability)#

    The game is Top-Down, so lighting is critical for depth perception.

    1. Rim Lighting: All characters must have a subtle rim light (fresnel) to pop from the background.
      • Player: Cyan rim light.
      • Enemy: Red rim light (subtle).
    2. Silhouette: Props must have clean outlines. Avoid visually noisy textures on the ground that confuse character movement.
    3. Contrast: Playable areas are 20% brighter than non-playable areas.
