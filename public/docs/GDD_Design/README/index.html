    High-Level Game Design Document#

    Extraction Topdown Mobile Multiplayer#

    For: Game Designers, Artists, 3D Artists, Level Designers, Sound Designers, UI/UX Designers

    ← Back to Main | View Technical GDD →

    Purpose#

    This document focuses on game design, art direction, and player experience. This is the primary reference for:

    • Game Designers designing mechanics and balance
    • Artists creating visual assets
    • Level Designers building maps
    • Sound Designers creating audio experience
    • UI/UX Designers designing interfaces

    Does not include: Implementation details, code, technical specifications (see Technical GDD)

    📚 Documentation Structure#

    🎮 Game Design#

    Core game design, mechanics, progression, and monetization systems

    • Overview - Game concept, pillars, target audience, competitive analysis
    • Core Gameplay - Gameplay loop, phases, player psychology, session flow
    • Controls & UX - Design philosophy, cross-platform strategy, accessibility
    • Progression - Player progression, XP, quests, battle pass
    • Economy - Monetization, currencies, pricing, marketplace, anti-fraud
    • Ranked Mode - Ranking system, matchmaking, competitive integrity, season rewards
    • Live Ops - Events, content calendar, monetization events, community management
    • Accessibility - Visual, auditory, motor, cognitive accessibility features
    • Localization - Supported languages, text guidelines, cultural adaptation

    📖 Story & Narrative#

    World lore, factions, and character backstories

    • Narrative - World lore, The Collapse, factions, operator backstories, environmental storytelling

    👥 Social & Multiplayer#

    Squad systems, clans, and community features

    • Multiplayer - Squad system, voice/text chat, ping system, clans, friends, anti-toxicity

    ⚔️ Combat Systems#

    Weapon design, items, and combat mechanics

    • Weapons - Weapon categories, modifications, combat mechanics, balance
    • Items & Economy - Item systems, loot, inventory, trading marketplace

    👤 Characters#

    Character design and abilities

    • Operators - Operator classes, abilities, progression, synergies, cosmetics

    🤖 AI & Enemies#

    Enemy design, behavior systems, and difficulty

    • Enemy Behavior - Enemy types, behavior systems, boss design, AI balancing

    🗺️ World Design#

    Maps, environments, and level design

    • Map Design - Map structure, zones, loot distribution, environmental storytelling

    🎨 Visual Design#

    Art direction and user interface

    • Art Direction - Visual style, color palette, character/environment art, VFX, animation
    • User Interface - UI/UX design, screen layouts, controls, accessibility

    🔊 Audio Design#

    Sound and music

    • Sound Design - Audio vision, combat audio, environmental audio, music, voice lines

    📋 Project Scope#

    Risks, boundaries, and project management

    • Risks - Design, technical, business, and operational risks with mitigation
    • Non-Goals - Explicit exclusions and what we intentionally won’t build

    📖 How to Use This Document#

    For Game Designers:

    • Read entirely to understand game vision
    • Reference when designing new mechanics
    • Update when there are balance changes

    For Artists:

    • Focus on Visuals section (Art Direction, UI)
    • Reference Characters and World for context
    • Follow guidelines when creating assets

    For Level Designers:

    • Deep dive into World → Map Design
    • Understand Core Gameplay Loop to design flow
    • Coordinate with Artists on visual style

    For Sound Designers:

    • Follow Audio → Sound Design guidelines
    • Reference Core Gameplay to understand audio cues
    • Coordinate with Game Designers on feedback

    For UI/UX Designers:

    • Follow Visuals → User Interface guidelines
    • Understand User Flow and player journey
    • Coordinate with Developers on technical constraints

    🎯 Design Philosophy#

    Player-First Design:

    • Every design decision must benefit player experience
    • Fair and balanced gameplay
    • Respect player’s time and effort

    Mobile-Optimized:

    • Controls must be intuitive and responsive
    • Matches designed for short sessions (10-15 minutes)
    • Performance across multiple devices

    Depth Through Simplicity:

    • Easy to learn, hard to master
    • Clear mechanics with deep strategy
    • Progressive complexity

    📝 Glossary#

    Core Terms:

    • Extraction: Process of leaving map with loot
    • Hot Zone: High-risk, high-reward areas
    • Operator: Playable character class
    • Stash: Permanent storage for extracted items
    • MMR: Matchmaking Rating
    • POI: Point of Interest
    • TTK: Time to Kill
    • DPS: Damage Per Second
