## Overview

Ranked Mode adds competitive stakes to extraction without turning the game into pure deathmatch. Success should reward extraction discipline, objective play, combat skill, and survival.

Ranked should feel like a stricter version of the same game, not a separate esport with different instincts. Players climb because they consistently make better raid decisions: they choose profitable risks, survive pressure, complete objectives, and leave before greed destroys the run.

The system should avoid rewarding kill-chasing as the only path upward. Combat matters, especially when it protects objectives or extraction, but the final score should still recognize that extraction shooters are about value secured, not only bodies dropped.

## Rank Ladder

The rank ladder gives players a seasonal identity. Each tier should have a clear emotional meaning, but the UI should avoid implying that lower-ranked players are worthless. Bronze and Silver are learning spaces; Gold and Platinum indicate consistency; Diamond and Champion indicate high-pressure mastery.

| Order | Rank | Meaning |
| :--- | :--- | :--- |
| 1 | Bronze | Entry ranked tier |
| 2 | Silver | Basic consistency |
| 3 | Gold | Solid extraction discipline |
| 4 | Platinum | Strong tactical and economy skill |
| 5 | Diamond | High-level competitive play |
| 6 | Champion | Top seasonal prestige |

## RP Inputs

RP inputs should be understandable from the post-match screen. A player should be able to see why the run gained or lost points and which decision mattered most. Hidden formulas can exist for anti-abuse tuning, but the visible scoring categories must remain stable.

| Input | Direction |
| :--- | :--- |
| Extraction | Primary positive RP source |
| Objective completion | Strong positive modifier |
| Combat performance | Positive, capped to avoid kill farming |
| Loot value extracted | Positive, capped by rank/mode |
| Death | Negative |
| Early disconnect | Strong negative unless protected by reconnect rules |

## Queue Rules

Queue rules are part of competitive integrity. Ranked should not start until the player understands extraction basics, owns enough gear context, and has completed tutorial requirements. Matchmaking should prefer fair, stable games over instant queues.

| Rule | Direction |
| :--- | :--- |
| Account requirement | Minimum level and tutorial completion |
| Squad rank spread | Limit rank gap for fairness |
| Map rotation | Seasonal and announced |
| Insurance | Disabled or restricted |
| Matchmaking | Rank, latency, party size, and integrity signals |

## Season Structure

| Phase | Purpose |
| :--- | :--- |
| Placement | Establish starting rank |
| Climb | Core ranked season |
| Mid-season patch | Balance and integrity update |
| Final push | Increased visibility and rewards |
| Reset | Soft reset plus reward distribution |

## Competitive Integrity

Integrity issues are more damaging in ranked because they affect trust in the ladder. Anti-cheat, disconnect policy, party restrictions, and suspicious pattern review should be communicated clearly enough that honest players understand why rules exist.

| Risk | Mitigation |
| :--- | :--- |
| Cheating | Anti-cheat, telemetry, review pipeline |
| Boosting | Party rank limits, suspicious pattern detection |
| Collusion | Match history and proximity analysis |
| Smurfing | Account age, performance spikes, phone/platform signals |
| Disconnect abuse | Reconnect window and escalating penalties |

## Rewards

Rewards should make ranked status visible without increasing combat power. The safest reward language is identity: badges, banners, titles, profile treatment, cosmetics, and end-of-season recognition.

| Reward | Rule |
| :--- | :--- |
| Rank badge | Seasonal, profile-visible |
| Cosmetic | No gameplay advantage |
| Banner/title | Prestige only |
| Leaderboard | Top players and squads |
| Clan contribution | Optional clan leaderboard points |

## Ranked Match Examples

A player extracts with moderate loot, completes an objective, and avoids unnecessary combat. This should be a positive ranked outcome because the player executed the extraction goal cleanly.

A squad wins several fights but dies to timeout while carrying high-value loot. Combat performance can soften the loss, but the result should still teach that ranked extraction requires leaving with value.

A player disconnects during a losing fight and fails to reconnect. The system should apply escalating penalties while preserving legitimate reconnect windows for network instability.

## Tuning Notes

- RP should reward extraction first, then objective quality, then capped combat contribution.
- Placement matches should reduce volatility for new ranked players.
- Party rank limits should prevent boosting without blocking normal friend groups too early.
- Leaderboards should distinguish solo, duo, trio, and clan contribution where possible.
