**Movement States Detailed:**

**Weight System Complete:**
```
0-15 kg:  100% speed (Normal)

25-35 kg: 75% speed, +50% stamina drain
35+ kg:   60% speed, +100% drain, NO sprint
```

#### 3. **Combat Mechanics - Deep Dive**

**Engagement Flow Diagram:**
```
Detection → Decision → Fight/Flee → Combat → Win/Lose
```

**Cover System:**
```
Soft Cover (Wood, Thin Metal)
├─ 30% damage reduction
├─ Penetrable
├─ Yellow outline

Hard Cover (Concrete, Thick Metal)
├─ 70% damage reduction
├─ Non-penetrable
├─ Blue outline
```

**Damage Calculation Formula:**
```
Base Damage
    ↓
[Distance Falloff]
    ↓
[Armor Absorption - 70%]
    ↓
[Headshot/Limb Multiplier]
    ↓
Final Damage
```

**Headshot System:**
```
No Helmet: 2.0x
Light Helmet: 1.75x (25% reduction)
Medium Helmet: 1.6x (40% reduction)
Heavy Helmet: 1.5x (50% reduction)
```

**Time-to-Kill Targets:**
```
Close (0-15m):  0.8-1.5 sec
Mid (15-40m):   1.2-2.5 sec
Long (40m+):    1.5-3.5 sec
```

**Design Philosophy:**
> "Fast enough for mobile satisfaction, slow enough for tactical decisions"

#### 4. **Looting Mechanics - Complete System**

**7 Container Types Defined:**
```
Wooden Crate
├─ Quality: Common-Uncommon (80/20)
├─ Time: 2 sec
├─ Items: 2-4

Metal Locker
├─ Quality: Common-Rare (50/40/10)
├─ Time: 3 sec
├─ Items: 3-5

Weapon Rack
├─ Quality: Weapons, Uncommon-Epic
├─ Time: 4 sec
├─ Items: 1-2

Safe
├─ Quality: Rare-Legendary (60/30/10)
├─ Time: 8 sec (or instant with key)
├─ Items: 4-8

Supply Drop
├─ Quality: Epic-Legendary (70/30)
├─ Time: 5 sec
├─ Items: 5-10

Dead Player Body
├─ Quality: Player's entire inventory
├─ Time: 3 sec
├─ Risk: Killer might be watching
```

**Dynamic Loot Scaling Formula:**
```
Loot Quality = Base * Zone * Time * Death

Zone Multiplier:
├─ Safe: 0.8x
├─ Mid: 1.0x
└─ Hot: 1.4x

Time Multiplier:
├─ 0-5 min: 1.0x
├─ 5-10 min: 1.1x
└─ 10-15 min: 1.25x (rewards late stay)

Death Multiplier:
└─ More deaths → 1.0x to 1.3x (better loot spawns)
```

#### 5. **Extraction Mechanics - Complete Process**

**5-Step Extraction:**
```
1. Reach Zone (green helicopter icon)
2. Enter Zone (UI prompt appears)
3. Activate (hold button)
4. Defend 30 seconds
   ├─ Can't leave zone
   ├─ Can't take damage
   └─ Timer resets if violated
5. Success! (fade to victory screen)
```

**3 Extraction Types:**
```
Standard (3-4 per map)
├─ Always active
├─ 30-sec timer
├─ Most contested

Emergency (1-2 per map)
├─ Requires special item
├─ 15-sec timer (faster!)
├─ Single-use

Vehicle (1 per map)
├─ 4 players max capacity
├─ 45-sec timer (longer)
├─ Very exposed
```

**Interruption System:**
- Leave zone → Reset
- Take damage → Reset
- Team death → Reset
- Zone attacked → Reset

#### 6. **Risk vs Reward Psychology**

**The "Greed Loop" Documented:**
```
Player has good loot
    ↓
Sees one more container
    ↓
"Just ONE more..." 
    ↓
Gets rare item
    ↓
"Okay, ONE more..."
    ↓
[Escalating greed]
    ↓
Extract (Dopamine HIGH) OR Die (Regret + Lesson)
```

**Design Mechanisms:**
```
1. Secure Container (safety net)
2. Visible Loot Value (see your risk)
3. Time Pressure (contamination)
4. Extraction Sounds (FOMO)
5. Quest Pressure ("need one more item")
```
