## Purpose

This glossary is the terminology reference for English and Vietnamese companion pages. Keep the English technical term when translation would reduce clarity or break a canonical game concept.

| Term | Usage rule |
| :--- | :--- |
| Raid | Keep as `raid`; translate only in explanatory prose when useful |
| Extraction | Keep as `extraction`; use “rút khỏi raid” as an explanation when needed |
| Loadout | Keep as `loadout` |
| Stash | Keep as `stash`; explain as persistent storage on first use |
| Operator | Keep as `operator` |
| Gear / Armor / Weapon | Keep the English game terms in technical specs; translate surrounding prose |
| Attachment | Keep as `attachment` |
| FIR | Keep as `FIR (Found in Raid)` |
| Contraband | Keep as `contraband` |
| Insured | Keep as `insured` |
| Entitlement | Keep as `entitlement` for account-level grants |
| Reward / Claim | Keep `reward`; keep `claim` in UI/action contexts |
| Season / Event | Keep both terms |
| Matchmaking | Keep as `matchmaking` |
| Debrief | Keep as `debrief` |
| Threat / Detection / Reinforcement | Keep these terms in AI and combat specs |

Technical identifiers, enum values, analytics events, file paths, class names, and function names must not be translated.
