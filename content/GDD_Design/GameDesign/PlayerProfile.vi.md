## Tổng Quan

The người chơi Profile communicates identity, mastery, history, và social trust. It should giúp người chơi celebrate progress while giving privacy controls for public information.

The profile should answer two different needs. For the owner, it is a career dashboard và memory book. For other người chơi, it is a social trust surface: who is this person, what do they play, are they active, và can I invite them safely?

Profile design must avoid shaming người chơi với raw stats alone. Extraction games involve learning, risk, và streaks of failure. The profile should celebrate milestones, favorite roles, memorable runs, và improvement as much as rank hoặc K/D.

## Profile Tabs

Tabs should separate identity from analysis. The Overview tab gives a quick read, while Stats và Match History support deeper review. Social actions nên được present nhưng not so aggressive that profile duyệt becomes spammy.

| Tab | Content | mục đích |
| :--- | :--- | :--- |
| Overview | Banner, title, favorite operator, chính stats | Fast identity read |
| Stats | Extraction rate, K/D, survival thời gian, loot giá trị | Performance review |
| Operators | Per-operator mastery và usage | Role identity |
| vũ khí | vũ khí usage, accuracy, favorite builds | Combat identity |
| Achievements | Badges, milestones, event trophies | Collection và pride |
| Match History | Recent raids, outcomes, rewards | Learning và review |
| Social | Friends, clan, invite actions | Connection |

## Public và Private Views

Privacy defaults should protect sensitive behavior such as match history, online status, và recent teammates. Public identity can still be expressive thông qua banners, titles, badges, và chosen showcase stats.

| Field | Own Profile | Public Profile | Privacy Option |
| :--- | :--- | :--- | :--- |
| Display name | Full | Full | No |
| hiện tại rank | Full | Full hoặc hidden | Yes |
| Career stats | Full | Summary | Yes |
| Match history | Full | Hidden by default | Yes |
| Clan | Full | hiển thị rõ | Yes |
| Online status | Full | Configurable | Yes |

## Career Metrics

Career metrics should teach what the game values. Extraction rate, loot giá trị, operator mastery, và streaks communicate survival và quyết định quality. K/D can be shown, nhưng it không nên dominate the profile.

| Metric | Why It Matters |
| :--- | :--- |
| Extraction rate | Measures survival và quyết định discipline |
| Average loot giá trị | Measures economy knowledge |
| Operator mastery | Shows role commitment |
| Favorite map | Shows người chơi identity |
| Highest rank | Competitive prestige |
| Longest extraction streak | Memorable achievement |

## Match History Row

Match history is a learning tool. Each row should giúp the người chơi remember what happened và decide what to do next: change route, adjust loadout, retry a quest, hoặc review a death.

| Field | Example |
| :--- | :--- |
| Outcome | Extracted / Killed / Timeout |
| Map | Industrial Zone |
| Mode | The Raid |
| Squad | Solo / Duo / Trio |
| Loot giá trị | Credits estimate |
| chính event | Boss kill, quest complete, rare item extracted |

## Profile Examples

A người chơi who extracts often nhưng avoids combat nên được able to show survival skill thông qua extraction rate, streaks, loot giá trị, và favorite roles. The profile không nên reduce all identity to K/D.

A ranked người chơi should have a rõ seasonal badge và history, nhưng privacy options should let them hide match history chi tiết nếu they do not want every route hoặc teammate hiển thị rõ.

A clan recruiter should quickly see activity, preferred modes, operator mastery, và social status mà không needing access to private match records.

## Profile Failure Cases

- nếu public stats encourage harassment, default visibility nên được reduced.
- nếu the profile hides all progress behind tabs, người chơi lose pride moments.
- nếu match history has no learning chi tiết, it becomes a trophy list instead of a review tool.
- nếu social actions are too aggressive, profile duyệt can become spam.

## Social Actions

| Action | Rule |
| :--- | :--- |
| Add friend | Respect privacy và block lists |
| Invite to party | Only nếu người chơi allows invites |
| View clan | Opens clan profile |
| Report | available from public profile và match history |
| Mute / block | Persistent account-level action |
