# UI_UX

## Start Here

- `_index.md` is the rendered UI/UX documentation hub.
- `Screen_Groups_Overview.md` defines the screen taxonomy and designer-ready spec template.
- `Global_UX_Standards.md` defines shared interaction, focus, state, modal, accessibility, and analytics rules.
- Lifecycle screen group pages contain detailed layout, ASCII wireframes, component requirements, states, input/focus/touch, designer notes, and acceptance checklists.

Canonical UI/UX documentation lives in the Markdown pages in this folder.

Generated `.html` pages are build output and should not be edited directly.
