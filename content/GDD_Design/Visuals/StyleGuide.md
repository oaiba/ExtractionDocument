## 🎨 Visual Identity Overview

### Style Definition

**Primary Style: Grounded Neo-Industrial**

```
REALISTIC ←──────●──────────→ STYLIZED
          ▲
     Game Position
     (70% Realistic, 30% Stylized)
```

**Characteristics:**
- Realistic materials and lighting
- Stylized readability for top-down perspective
- Gritty, weathered aesthetic
- Tech-enhanced with neon accents
- Post-apocalyptic industrial decay

---

## 🖼️ Visual Pillars

### Pillar 1: "Decay with Memory"

**Concept:** A collapsing world that still bears traces of its civilized past.

**Visual Elements:**
| Past Glory         | Current Decay            |
| :----------------- | :----------------------- |
| Corporate logos    | Faded, broken signage    |
| Clean architecture | Rust, cracks, overgrowth |
| Modern equipment   | Abandoned, scavenged     |
| Organized spaces   | Chaotic, looted          |

**Color Trend:**
```
Before:   🟦⬜🟦⬜  (Clean, corporate)
          ↓
After:    🟤🟠⬛🟢  (Rust, decay, nature)
```

### Pillar 2: "Tactical Clarity"

**Concept:** Every element must be readable from a top-down perspective.

**Rules:**
1. Strong silhouettes (recognizable at 50m+)
2. Color-coded gameplay elements
3. High contrast between player and environment
4. Clear visual hierarchy

**Hierarchy:**
```
1. [PLAYER]    → Brightest, most saturated
2. [ENEMIES]   → High contrast red
3. [LOOT]      → Glowing, color-coded
4. [COVER]     → Neutral, readable
5. [BACKGROUND]→ Desaturated, atmospheric
```

### Pillar 3: "Functional Fashion"

**Concept:** Everything must look like it has a practical purpose.

**Not This:** Fantasy armor, glowing runes, magical effects
**But This:** Tactical gear, worn equipment, practical modifications

**Material Focus:**
- Kevlar, ballistic nylon
- Weathered metal, polymer
- Medical fabrics, pouches
- Tech devices with subtle LEDs

## 💡 Lighting Design

### Lighting Philosophy

**Goals:**
1. Enhance readability from top-down
2. Create atmosphere and mood
3. Guide player attention
4. Differentiate zones

### Outdoor Lighting

**Primary: Overcast Day (Default)**
```
Sun Direction: 45° angle (soft shadows)
Sun Color: Warm white #FFF7ED
Intensity: 2.0 (lux)
Sky: Gray-blue overcast #94A3B8
Ambient: Cool #E0E7FF
Shadow Softness: 0.7

Mood: Somber, industrial, realistic
```

**Secondary: Golden Hour (Events)**
```
Sun Direction: Low angle (15°)
Sun Color: Deep orange #F97316
Intensity: 1.5
Sky: Gradient orange → purple
Shadow Color: Deep blue #1E3A8A
Shadow Length: Long

Mood: Dramatic, tense, beautiful danger
```

### Indoor Lighting

**Industrial Interiors:**
```
Primary: Overhead fluorescent (flickering)
Color: Cool white #F0F9FF with green tint
Intensity: Variable (broken fixtures)
Fill: Window light (motivated)
Accent: Warning lights (orange/red)
Shadow: High contrast

Mood: Abandoned, unsettling, industrial
```

**Office/Corporate Interiors:**
```
Primary: Soft overhead panels
Color: Neutral white #FAFAFA
Intensity: Lower (power issues)
Fill: Computer screen glow (cyan)
Accent: Emergency exit signs (green)
Shadow: Soft

Mood: Corporate decay, eerie quiet
```

**Underground/Labs:**
```
Primary: Emergency lighting only
Color: Deep red #DC2626 or Cyan #06B6D4
Intensity: Low, dramatic
Fill: Equipment glow
Accent: Hazard lights (yellow pulse)
Shadow: Very high contrast

Mood: Danger, sci-fi horror, secrets
```

### Zone-Specific Lighting Moods

| Zone           | Light Temp | Key Light   | Fill         | Mood           |
| :------------- | :--------- | :---------- | :----------- | :------------- |
| Edge/Forest    | 5500K      | Overcast    | Blue ambient | Safe, natural  |
| Mid/Urban      | 4500K      | Mixed       | Warm bounce  | Transitional   |
| Hot/Industrial | 4000K      | Harsh spots | Orange fill  | Dangerous      |
| Core/Labs      | 6500K+     | Colored     | Minimal      | Extreme danger |

## 🏙️ Environment Style Guide

### Industrial Zone Visual Language

**Key Visual Elements:**
- Massive smokestacks (landmark)
- Rusted catwalks and gantries
- Conveyor belts (non-functional)
- Chemical tanks with warning labels
- Graffiti (survivor messages)
- Nature reclaiming (vines, moss)

**Material Palette:**
```
60% - Corrugated metal (rusted)
20% - Concrete (cracked, stained)
10% - Remnant paint (faded corporate)
10% - Organic intrusion (plants, mold)
```

### Urban Zone Visual Language

**Key Visual Elements:**
- High-rise buildings (varied damage)
- Street-level storefronts
- Abandoned vehicles
- Billboard frameworks (empty)
- Public art (damaged)
- Makeshift barricades

**Material Palette:**
```
40% - Concrete/brick
30% - Glass (broken, boarded)
15% - Asphalt (cracked)
15% - Nature overgrowth
```

### Military Zone Visual Language

**Key Visual Elements:**
- Bunkers and blast walls
- Watchtowers
- Razor wire perimeters
- Camouflage netting
- Vehicle wrecks (military)
- Active defense systems

**Material Palette:**
```
50% - Reinforced concrete
30% - Olive drab metal
15% - Sandbags/earthworks
5% - High-tech panels
```

## 👤 Character Style Guide

### Operator Visual Identity

**Body Proportions:**
```
Style: Realistic-heroic hybrid
Head: 1/7.5 of body (slightly larger for readability)
Shoulders: 2 heads wide (men), 1.8 heads (women)
Silhouette: Clear class distinction
```

**Gear Layering System:**
```
Layer 1: Base clothing (undersuit, shirt)
Layer 2: Primary armor (vest, plates)
Layer 3: Pouches and equipment
Layer 4: Accessories (helmet, goggles)
Layer 5: Backpack (if equipped)
```

## 🔫 Weapon Style Guide

### Weapon Visual Philosophy

**Principles:**
1. Grounded in real-world firearms
2. Visible wear and personalization
3. Clear type identification
4. Attachment modularity visible

**Wear Levels:**
```
Factory New   - 5% of weapons  - Clean, shiny
Field-Tested  - 30% of weapons - Minor scratches
Well-Worn     - 40% of weapons - Visible use marks
Battle-Scarred- 20% of weapons - Heavy damage
Veteran       - 5% of weapons  - Heavy wear + custom
```

### Attachment Visibility

```
Scope     → Top rail mount (visible profile change)
Suppressor→ Barrel extension (+30% length)
Grip      → Underbarrel (silhouette change)
Magazine  → Body side (size varies by capacity)
Laser     → Side rail (visible red/green beam)
```

## 📐 Composition Guidelines

### Top-Down Framing

**Screen Layout:**
```
┌─────────────────────────────────────────┐
│          SAFE ZONE (UI)                 │
├─────────────────────────────────────────┤
│                                         │
│      FOCUS AREA (Player + Combat)       │
│           ●──player──●                  │
│                                         │
├─────────────────────────────────────────┤
│          SAFE ZONE (Controls)           │
└─────────────────────────────────────────┘
```

**Visual Weight Distribution:**
- Center: Player (highest contrast)
- Near: Immediate threats (high contrast)
- Mid: Environment detail (medium contrast)
- Far: Atmosphere (low contrast, fog)

### Readability Zones

```
0-50 units    │ Full detail, all effects
50-100 units  │ High detail, reduced particles
100-200 units │ Medium detail, billboard vegetation
200+ units    │ Low detail, simplified
```
