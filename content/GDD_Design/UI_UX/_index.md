## 👆 Designing the Interaction

Good UX is invisible. It gets the player into the game faster and makes complex systems intuitive.

### Principles
*   **Minimal Clicks:** Every action should take the minimum number of inputs.
*   **Clear Feedback:** Every button press must have visual/audio confirmation.
*   **Console First:** All menus must be navigable with a D-Pad.
