### Security Philosophy

*   **Server Authority:** Never trust the client. Movement, damage, and loot validation happen on the server.
*   **Defense in Depth:** Multiple layers of protection (obfuscation, encryption, server validation, analytics).
*   **Fair Play:** Protecting the integrity of the extraction loop is paramount for player retention.
