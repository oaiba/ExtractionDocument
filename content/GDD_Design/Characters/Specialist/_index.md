## Class Overview

The **Specialist** class operators bring utility and disruption to the battlefield. They excel at countering enemy abilities and controlling the flow of combat through tech-based tools.

### Class Identity

| Attribute           | Value                | Notes                  |
| :------------------ | :------------------- | :--------------------- |
| **Role**            | Utility / Disruption | Control specialists    |
| **Difficulty**      | ★★★★★                | Hard - Requires timing |
| **Team Dependency** | Medium               | Enables team, can solo |
| **Skill Ceiling**   | Very High            | Knowledge-based        |

### Class Traits (All Specialist Operators)

| Trait                  | Effect                        | Gameplay Impact    |
| :--------------------- | :---------------------------- | :----------------- |
| **Expanded Inventory** | +2 Inventory Slots            | More loot capacity |
| **Tech Savvy**         | +20% Gadget Interaction Speed | Faster hacking     |
| **Distracted**         | -10% Weapon Accuracy          | Combat penalty     |
