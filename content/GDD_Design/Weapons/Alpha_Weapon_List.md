## 🔫 Philosophy & Baseline
Weapons in **Aethelgard** follow a "Realism-Lite" approach.
*   **Recoil:** Defined by `Vertical` (Climb) and `Horizontal` (Bounce). Lower is better.
*   **Ergonomics:** Determines ADS speed, Stamina drain, and Noise levels. Higher (0-100) is better.
*   **Fire Rate (RPM):** Fixed per receiver. Cannot be changed by mods.
*   **MOA (Accuracy):** Dispersion at 100 yards. Lower is better.

## 📊 Assault Rifles (ARs)

### 1. Colt M4A1 (5.56x45mm NATO)
**Archetype:** High-ROF, Low Recoil Potential, Expensive.
*   **Role:** The "Meta" king. High initial cost, but scales arguably the best with attachments.
*   **Feel:** Snappy, high vertical climb that settles quickly.

| Stat                  | Base Value | Fully Modded (Est) | Notes                                      |
| :-------------------- | :--------: | :----------------: | :----------------------------------------- |
| **Vertical Recoil**   |     85     |         32         | Requires expensive gas block/muzzle combo. |
| **Horizontal Recoil** |    210     |        125         | Horizontal bounce is its main weakness.    |
| **Ergonomics**        |     48     |         75         | Heavy barrels reduce Ergo significantly.   |
| **Fire Rate**         |  800 RPM   |      800 RPM       | Excellent TTK.                             |
| **Effective Range**   |    500m    |        650m        | 5.56 maintains velocity well.              |
| **Accuracy (MOA)**    |    1.8     |        1.1         | -                                          |

**Mod Slots (12+):**
*   Muzzle, Barrel (260mm - 508mm), Gas Block, Handguard, Foregrip, Receiver (Upper), Charge Handle, Sight (Rear/Front), Scope, Stock, Pistol Grip, Magazine (30/40/60/100).

### 2. Kalashnikov AKM (7.62x39mm)
**Archetype:** High Damage, High Recoil, Budget Friendly.
*   **Role:** The "great equalizer." Hard to control, but penetrates armor cheaply.
*   **Feel:** Heavy, "chuggy" recoil pulse. Visual recoil is high.

| Stat                  | Base Value | Fully Modded (Est) | Notes                                     |
| :-------------------- | :--------: | :----------------: | :---------------------------------------- |
| **Vertical Recoil**   |    105     |         55         | Never truly laser-beam accurate.          |
| **Horizontal Recoil** |    180     |        130         | More predictable pattern than M4.         |
| **Ergonomics**        |     42     |         58         | Heavy wood/steel construction hurts Ergo. |
| **Fire Rate**         |  600 RPM   |      600 RPM       | Slower ROF helps control recoil.          |
| **Effective Range**   |    350m    |        450m        | Bullet drops significantly after 300m.    |
| **Accuracy (MOA)**    |    2.5     |        1.9         | Not a sniper platform.                    |

**Mod Slots (8+):**
*   Muzzle, Dust Cover, Rear Sight, Gas Tube, Handguard, Foregrip, Stock, Pistol Grip, Magazine (10/30/40/73).

## 🚄 Submachine Guns (SMGs)

### 3. H&K MP5 (9x19mm)
**Archetype:** Laser Accuracy, Low Stopping Power (unless AP).
*   **Role:** CQC headshot machine or "Leg Meta" hose.
*   **Feel:** Almost zero recoil. "Point and click" interface.

| Stat                  | Base Value | Fully Modded (Est) | Notes                              |
| :-------------------- | :--------: | :----------------: | :--------------------------------- |
| **Vertical Recoil**   |     32     |         22         | Lowest in standard class.          |
| **Horizontal Recoil** |    150     |        110         | Very tight spread.                 |
| **Ergonomics**        |     65     |         78         | Fast ADS, low stamina drain.       |
| **Fire Rate**         |  800 RPM   |      800 RPM       | Matches M4A1 fire rate.            |
| **Effective Range**   |    80m     |        120m        | Damage drops off sharply past 50m. |
| **Accuracy (MOA)**    |    3.5     |        3.0         | -                                  |

**Mod Slots (5+):**
*   Muzzle (or Integrated SD), Handguard, Foregrip, Mount (Claw), Scope, Stock, Magazine (20/30/50).

## 🔫 Sidearms

### 4. Glock 17 (9x19mm)
**Archetype:** Reliable Backup, Emergency Speed.
*   **Role:** Finishing off targets or sprint-speed runs.
*   **Feel:** Snappy, crisp visual return to center.

| Stat                  | Base Value | Fully Modded (Est) | Notes                                |
| :-------------------- | :--------: | :----------------: | :----------------------------------- |
| **Vertical Recoil**   |    250     |        180         | Visual kick is high (slide motion).  |
| **Horizontal Recoil** |     80     |         60         | Minimal side-to-side.                |
| **Ergonomics**        |     85     |         92         | Fastest switch speed in game.        |
| **Fire Rate**         | Semi (450) |     Semi (450)     | Cap dependent on player click speed. |
| **Effective Range**   |    50m     |        70m         | -                                    |
| **Accuracy (MOA)**    |    4.0     |        2.5         | Hex slide improves accuracy.         |

**Mod Slots (6+):**
*   Muzzle, Slide, Sights (RMR), Laser/Light, Magazine (17/21/33/50).

## 💥 Shotguns

### 5. Remington Model 870 (12 Gauge)
**Archetype:** Burst Damage, Pump Action.
*   **Role:** Early game dominator, Corner holding.
*   **Feel:** Massive kick, satisfying mechanical "pump" sound.

| Stat                  | Base Value | Fully Modded (Est) | Notes                                 |
| :-------------------- | :--------: | :----------------: | :------------------------------------ |
| **Vertical Recoil**   |    510     |        320         | Requires re-aiming after every shot.  |
| **Horizontal Recoil** |    250     |        200         | -                                     |
| **Ergonomics**        |     35     |         55         | Slow to shoulder, slow to swing.      |
| **Fire Rate**         |  ~30 RPM   |      ~35 RPM       | Pump speed affects follow-up.         |
| **Effective Range**   |    40m     |        80m         | Ammo dependent (Slug vs Buck).        |
| **Accuracy (MOA)**    |    10.0    |        5.0         | High dispersion (Spread) effectively. |

**Mod Slots (6+):**
*   Muzzle (Choke/Brake), Barrel (Short/Long), Forend (Pump), Stock, Receiver Mount, Magazine Tube (4/6/8/10).
