## Overview

This document defines **stash size** by edition and Hideout level, **container unlock path** (order and method), and **secure container upgrade path**. For container specs see [Storage Master Database](Storage_Master_Database.md).

---

## Stash Size Progression

Stash is the player’s persistent out-of-raid storage. **Stash capacity = total cells** (single grid; 10×28 = 280 cells, etc.). Grid size can increase with edition or Hideout upgrades.

| Edition / source | Stash grid | Total cells | Unlock cost / note |
| :--------------- | :--------- | :---------: | :------------------ |
| Standard Edition | 10×28 | 280 | Free |
| Hideout Lvl 2 | 10×38 | 380 | 3.5M + materials |
| Hideout Lvl 3 | 10×48 | 480 | 8.5M + materials |
| Hideout Lvl 4 | 10×68 | 680 | 15M + materials |
| Premium Edition | 10×48 | 480 | Free (start) |
| Ultimate Edition | 10×68 | 680 | Free (start) |

All editions can reach the same maximum (e.g. 10×68) via Hideout; premium/ultimate start with a larger grid.

## Container Unlock Path

Order in which stash-only containers and key tools become available. Exact levels and quest names are placeholders.

| Phase | Container (examples) | How to unlock | Estimated level |
| :---- | :------------------- | :------------ | :-------------- |
| Early | Keytool, Docs Case | Trader Lvl 1 purchase | 1–5 |
| Early–Mid | Ammo Case, Scav Junkbox | Trader Lvl 2 or craft | 10–15 |
| Mid | Med Case, Magazine Case | Trader Lvl 2 / quest | 15–20 |
| Mid–Late | Weapon Case | Trader Lvl 3 / quest chain | 20–30 |
| Late | Items Case | Trader Lvl 3 / barter | 30–40 |
| Endgame | THICC Items, THICC Weapon | Trader Lvl 4 / quest chain | 40+ |

## Secure Container Upgrade Path

Secure container size is upgraded via quests or edition; it is not purchased as a consumable. **Cells** in the table below = **total capacity** (see [Storage Master Database](Storage_Master_Database.md)).

| Container | Grid | Cells (total capacity) | Unlock method |
| :-------- | :--: | :---: | :------------ |
| Alpha | 2×2 | 4 | Default (all editions) |
| Beta | 2×3 | 6 | Quest (e.g. Punisher line, mid-game) |
| Gamma | 3×3 | 9 | Premium Edition OR quest (e.g. The Collector, late-game) |
| Kappa | 3×4 | 12 | Quest: complete all main quests (endgame prestige) |

Standard-edition players can reach Gamma/Kappa by progression; premium gives Gamma from the start. Kappa is progression-only (no edition shortcut).
