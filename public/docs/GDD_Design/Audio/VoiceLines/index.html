    🎙️ Voice Design Philosophy#

    Core Principles#

    “Short, Clear, Character” - Every voice line must be:

    1. Functional: Provide gameplay information
    2. Brief: No longer than 3 seconds
    3. Distinctive: Identify the character
    4. Contextual: Fit the situation

    👤 Operator Voice Profiles#

    ASSAULT - “Ghost” (Marcus Chen)#

    Voice Characteristics:

    Tone: Deep, gravelly
Accent: Slight Hong Kong English
Pace: Clipped, military-precise
Emotion: Suppressed anger, dark humor
Age Sound: Mid-30s

    Voice Actor Direction:

    • Sounds like someone who’s seen too much
    • Rarely raises voice (controlled intensity)
    • Occasional dark sarcasm
    • Protective undertone when mentioning teammates

    Combat Callouts:

    Trigger Line Options

    Low Ammo “Running dry.” / “Last mag.” / “Need ammo.”
    Enemy Spotted “Contact.” / “Eyes on hostile.” / “Enemy, 12 o’clock.”
    Taking Fire “Taking fire!” / “Under attack!” / “Shots incoming!”
    Grenade Throw “Frag out.” / “Grenade.” / “Fire in the hole.”
    Kill “Target down.” / “One less.” / “Eliminated.”
    Headshot “Clean shot.” / “Perfect.” / “Right between the eyes.”
    Downed “I’m hit… bad.” / “Going down…” / “Man down…”
    Reviving “I got you.” / “Stay with me.” / “You’re not dying today.”

    Ability Lines:

    Ability Activation During End
    Combat Stim “Juicing up.” heavy breathing “Coming down…”
    “Let’s do this.” heartbeat sounds “That’s the stuff.”

    Situational Lines:

    Situation Lines
    Match Start “Lock and load.” / “Let’s get this done.”
    Extraction Called “Evac incoming, move.” / “Ride’s here.”
    Successful Extract “We made it.” / “Another day.”
    Teammate Death “Damn it…” / silent moment
    Finding Good Loot “This’ll do.” / “Not bad.”
    Low Health pained breathing / “Just a scratch…”

    📋 Voice Line Categories#

    Automatic Callouts (AI-Triggered)#

    Combat Callouts:
├── Reload: When reloading begins
├── Low Ammo: When magazine < 25%
├── Enemy Spotted: First contact with enemy
├── Taking Fire: When receiving damage
├── Grenade: When throwing or enemy throws
├── Kill: On elimination
├── Special Kill: Headshot, multi-kill
├── Downed: When entering downed state
└── Reviving: When reviving teammate

Status Callouts:
├── Low Health: Below 25% HP
├── Healing: When using healing items
├── Ability Ready: Cooldown complete
├── Ability Use: Activation
└── Loot Found: Discovering high-tier items

    Manual Callouts (Player-Triggered)#

    Communication Wheel:
├── "Enemy Here" - Ping location
├── "Follow Me" - Rally command
├── "Wait"/"Hold" - Stop movement
├── "Need Help" - Request assistance
├── "Thanks" - Appreciation
├── "Yes"/"Affirmative" - Confirm
├── "No"/"Negative" - Decline
└── "Good Game" - Match end courtesy

    🔊 Voice Technical Specs#

    Recording Requirements#

    Format: WAV 48kHz, 24-bit
Delivery: OGG Vorbis for runtime
Noise Floor: < -60dB
Peak Level: -3dB max
Room Tone: Recorded, matched to game

Per Operator:
├── Combat lines: 60-80 lines
├── Ability lines: 15-20 lines
├── Situational: 30-40 lines
├── Effort sounds: 50+ variations
└── Total: ~150-200 unique files

Per NPC:
├── Quest dialogue: 20-30 lines
├── Greetings: 5-10 variations
├── Farewells: 5-10 variations
└── Total: ~40-50 unique files

    Playback Rules#

    Cooldown Between Lines: 3 seconds minimum
Priority System:
├── Critical (Grenade warning): Interrupt all
├── Combat (Reload, contact): High priority
├── Status (Low ammo): Medium priority
└── Flavor (Loot): Low priority, can be skipped

Teammate Audio:
├── Reduced by 50% vs own operator
├── Spatially positioned
└── Can be muted in settings
