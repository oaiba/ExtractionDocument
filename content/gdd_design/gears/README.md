# Gears

Gears defines physical equipment the operator wears or carries in raid: armor, helmets, headsets, rigs, backpacks, secure containers, and stash-only cases. Gear power is earned, found, crafted, traded, or quest-granted; Commerce may unlock cosmetics, but it does not grant paid combat-power item instances.

## Canonical Rules

| Topic | Rule |
| ----- | ---- |
| Tier vs rarity | Tier is a balance/progression bracket; rarity is scarcity/presentation/economy signal |
| No item level | Gear has no per-item level, +1/+2 upgrade power, or premium stat scaling |
| Practical value | Armor class, zones, durability, repairability, weight, storage capacity, access speed, and restrictions define real value |
| Comparison | UI must explain trade-offs in text, not only green/red stat deltas |
| Restricted states | Locked, contraband, insured, ineligible, protected, damaged, and broken states need readable reasons |
