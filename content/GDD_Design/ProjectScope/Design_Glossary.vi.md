## Mục Đích

Glossary này là reference thuật ngữ cho các trang English và bản tiếng Việt companion. Giữ technical term tiếng Anh khi dịch sẽ làm giảm độ rõ hoặc phá canonical game concept.

| Thuật ngữ | Quy tắc sử dụng |
| :--- | :--- |
| Raid | Giữ `raid`; chỉ giải thích bằng tiếng Việt khi cần |
| Extraction | Giữ `extraction`; có thể giải thích là “rút khỏi raid” |
| Loadout | Giữ `loadout` |
| Stash | Giữ `stash`; giải thích là persistent storage ở lần đầu |
| Operator | Giữ `operator` |
| Gear / Armor / Weapon | Giữ English term trong technical spec, dịch phần prose xung quanh |
| Attachment | Giữ `attachment` |
| FIR | Giữ `FIR (Found in Raid)` |
| Contraband | Giữ `contraband` |
| Insured | Giữ `insured` |
| Entitlement | Giữ `entitlement` cho grant cấp account |
| Reward / Claim | Giữ `reward`; giữ `claim` trong UI/action context |
| Season / Event | Giữ cả hai thuật ngữ |
| Matchmaking | Giữ `matchmaking` |
| Debrief | Giữ `debrief` |
| Threat / Detection / Reinforcement | Giữ các term này trong AI và combat spec |

Không dịch technical identifier, enum value, analytics event, file path, class name và function name.
